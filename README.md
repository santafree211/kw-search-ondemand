# KW-Search オンデマンド自動探索コントローラー (Desktop Edition)

完全オンデマンド・常時稼働サーバー不要で稼働する、KW-Search リサーチパイプラインの専用デスクトップUIです。

## 概要
- **オンデマンド実行**: 必要な時だけローカルで実行。
- **設計メモ + 実コード構成**: 全てのファイル先頭に詳細な設計メモ（Design Note）を完備。
- **1ファイル・1責務**: `カテゴリ_機能.py` 命名規則を採用。

## ファイル構成
- `起動.bat`: ワンクリック起動用バッチ
- `KWサーチ起動.lnk`: 背景画面なしで起動するショートカット
- `view_main_window.py`: メインウィンドウ統合ビュー
- `view_tab_run.py`: パイプライン実行＆リアルタイムログ表示タブ
- `view_tab_audit.py`: 黄金比率＆3者突合監査タブ
- `view_tab_genre.py`: 50ジャンル水位進捗タブ
- `service_runner.py`: プロセス制御・Kill・ログ収集サービス
- `core_config.py`: 定数・パス設定・テーマ設定
