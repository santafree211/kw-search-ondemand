# Module: research_domain_extract

## 1. 責務（Single Responsibility）
特定ドメイン（特にSERP分析で発見されたDA 1〜9の個人ブログドメイン）を受け取り、Ubersuggest APIの `domain_keywords` エンドポイントを**1回のみ呼び出し**、そのサイトが上位表示（1〜10位）されている全キーワードと月間検索ボリューム（`volume`）を一括取得する。
取得したデータから `volume >= 1900` かつ `position <= 10` の勝ちキーワードを自動抽出し、実測ボリュームキャッシュ（`verified_volume_cache.json`）にアトミックに保存する。

## 2. APIトークン節約効果
- **従来**: サイト内の有望キーワードを推測して単発APIで1つずつ確認（10〜30枠消費）。
- **本モジュール（バルク `domain_keywords`）**: そのサイトが持っている全上位キーワードとボリュームが **1枠** で完全に手に入る（**90%〜95%削減**）。

## 3. 入力引数
- `Domain`: 対象ドメイン（例: `example.com`）
- `MinVolume`: 下限月間検索ボリューム（デフォルト: 1900）
- `MaxPosition`: 上限掲載順位（デフォルト: 10）
- `Limit`: 取得最大件数（デフォルト: 50）
- `LocId`: 地域ID（デフォルト: 2392 / 日本）
- `Language`: 言語コード（デフォルト: "ja"）
- `Excludes`: 除外キーワード配列（スプレッドシート既存KW等）
- `DryRun`: APIを呼び出さずキャッシュまたはモックから検証するスイッチ

## 4. 出力仕様
- `WinningKeywords`: ボリューム1,900以上、順位10位以内の勝ちキーワード一覧
- `TotalFetched`: 取得された全キーワード数
- `PassedCount`: 条件を満たした勝ちキーワード数
- `NewCacheEntries`: 新規にキャッシュへ記録されたキーワード数

## 5. ガードレール・禁止事項
- 返却された `volume` を手動補正することは禁止（第6条）。
- 順位が11位以下のキーワードを10位以内と偽って抽出することは禁止。
